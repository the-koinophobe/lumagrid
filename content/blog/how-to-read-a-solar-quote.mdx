Two quotes can look the same and be very different. Here is how to read one, line by line.

## A good quote, explained

<div className="table-scroll">

| Line | What to check |
|---|---|
| Inverter | Brand, model, kVA, pure sine wave, MPPT |
| Battery | Chemistry (LiFePO4), **kWh**, brand, cell grade |
| Panels | Brand, model, **watts**, how many |
| Mounting | Rails and clamps, roof type |
| DC cable | Size (e.g. 6mm² PV cable), length |
| AC cable | Size, to your distribution board |
| Protection | DC breaker/fuse, AC breaker, surge protection |
| Earthing | Earth rod and cable |
| Labour | Installation, testing, handover |
| Transport | Shown separately if outside Port Harcourt |
| Warranty | Workmanship + products, in writing |

</div>

## Red flags

- One total, no breakdown
- "2 batteries" with no kWh
- "Any brand" panels
- No protection or earthing lines
- Verbal warranty only

## Compare quotes side by side

Make a simple table:

1. Battery kWh
2. Panel watts × count
3. Inverter model
4. Protection listed?
5. Warranty years

Then compare **price**. Read [cheap vs quality installation](/blog/cheap-vs-quality-solar-installation).

## Translate the units

- **kVA** = what you can run at once
- **kWh** = how long it lasts
- **W** = panel size

See [kVA vs kW vs kWh](/blog/kva-vs-kw-vs-kwh-explained).
